# Guía de Instalación y Primeros Pasos

## Requisitos
- **Servidor:** Paper, Purpur o Spigot (1.21.x).
- **Java:** Java 21 (Temurin / OpenJDK 21).
- **Compatibilidad Opcional:** GeyserMC + Floodgate (Bedrock), FastLogin (Premium).

## Pasos de Instalación
1. Descarga `SmartLogin-1.0.0.jar`.
2. Muévelo a la carpeta `plugins/`.
3. Inicia el servidor. Al entrar el primer Operador (OP), se abrirá automáticamente el **Setup Wizard GUI** interactivo para configurar idioma y base de datos en 30 segundos.
